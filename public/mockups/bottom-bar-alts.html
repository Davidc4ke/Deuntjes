Bottom bar — alternative designsiPhone scale · 390 px

Each panel below is rendered at actual iPhone width with thumb-friendly 48 px controls (slider rails get 20 px knobs). All three add Volume, Length and per-stage ADSR on top of the existing Copy / Delete / Done + transport.

A

Value-pills row

Every parameter is a single 48 px pill showing its current value. Tap a pill → one-knob popover slides up. Two stacked rows; bottom row scrolls horizontally if more params arrive.

Selection · 2 notes
+ stays narrow; scrolls if more params; values readable at a glance.
− every adjustment is a 2-step tap (pill → popover slider).
B

Inline-slider strip

Sliders are right there — no second tap. Vol and Len each get full-width sliders; ADSR gets a 4-up row below. Actions live on their own row so they stay the same size as everything else.
