Bottom bar — alternative designsselection mode · 2 notes

All three keep the same button skeleton (height, radius, padding, type scale) so nothing feels like a one-off control. Each adds Volume, Length and per-stage ADSR on top of the existing Copy / Delete / Done + transport.

AValue-pills row

Every parameter is a single pill showing its current value. Tapping a pill opens a one-knob popover (like the existing channel-mute charging). Two compact rows: actions on top, parameters below. Total height: ~96 px.

Selection · 2 notes

+ stays compact; horizontal scroll if more params appear; reads like a status strip.

− every adjustment costs a tap-then-drag; you can't eyeball values at a glance.

BInline-slider strip

Sliders are visible directly in the dock — no extra tap to adjust. Vol and Len get full-width sliders; ADSR sits in a 4-up row below. Actions sit on a third row to keep them at the same size as the other dock buttons. Total height: ~152 px.
